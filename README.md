## Selected projects

### [Baseball Pitching Timing Analysis](https://github.com/ziyuzhang2025/pitching-analysis)

A local computer-vision tool that uses Python, OpenCV, MediaPipe, NumPy, Pandas, and Streamlit to analyse pitching-sequence timing. It supports pose overlays, event review, manual calibration, and evaluation against labelled frames.

### [Gym Log](https://github.com/ziyuzhang2025/gym-log) · [Live app](https://gym-log-ochre.vercel.app)

A responsive workout and nutrition application built with Next.js, React, TypeScript, Supabase, PostgreSQL, and Row Level Security. It includes authentication, workout planning, session history, and nutrition tracking.

### [QR Restaurant Ordering](https://github.com/ziyuzhang2025/ordering-sys) · [Live app](https://ordering-sys-rosy.vercel.app)

A database-backed ordering workflow built with Next.js, TypeScript, Prisma, and PostgreSQL, covering customer ordering, store administration, menu management, order status, and revenue history.

### [Zhanyang Mining Website](https://github.com/ziyuzhang2025/zhanyang) · [Live site](https://zhanyang.vercel.app)

A responsive business website and Vue 3 CMS demonstration with reusable components, LocalStorage CRUD, structured data loading, validation, and documented content-integrity boundaries.
